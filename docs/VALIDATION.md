## 1. 测试原则

- 使用自己拥有/获准调试的设备；所有授权需由用户主动开启。
- 在可信 Wi-Fi 下测试。不要把调试端口暴露到公网。
- 日记 App 内使用**虚构测试文本**，不记录真实日记、账号、配对码、设备唯一标识或个人截图。
- 区分官方文档、桌面工具输出、模拟器与真实手机证据。
- 测试状态统一：PASS / FAIL / BLOCKED / NOT TESTED。

## 3.1 模拟器实测记录（2026-10-28）

**载体：** DevEco Studio 模拟器 Mate 90 Pro，`API 26`，`7.0.0.107`，`uitest 7.0.0.1`。
**对象：** 系统浏览器地址栏 `TextInput`（`id=url_input_in_search`），全部使用虚构串。
**注意：** 这是模拟器 + 系统应用，**不是真机，也不是第三方日记 App**。

| ID | 测试项 | 实际结果 | 状态 |
| --- | --- | --- | --- |
| E-01 | 系统中是否存在 adb | 无 adb 二进制 | **FAIL**（scrcpy 路线不可用） |
| E-02 | `uitest` / `uinput` 是否存在 | 均在 `/system/bin`，shell(uid 2000) 可执行 | PASS |
| E-03 | ASCII 文本注入 | `ABC123xyz` 写入并被回读 | PASS |
| E-04 | 中文文本注入 | `你好世界测试` 追加到光标处并被回读 | PASS |
| E-05 | 清空输入框 | Ctrl+A + 退格后清空 | PASS |
| E-06 | 方向键定位光标 | 预期 `AXB`，实际 `XAB` | **FAIL**（语义待查） |
| E-07 | 无焦点时注入 | 返回 `No Error`、退出码 0，文字被静默丢弃 | **FAIL**（静默失败） |
| E-08 | `uinput -K -t` 中文 | `The character of index 0 is invalid.` | **FAIL**（仅 ASCII，符合文档） |
| E-09 | 单次命令延迟 | 10 次共 3039 ms，均值 **304 ms/次** | 已测量 |
| E-10 | 剪贴板副作用 | 该控件 Ctrl+C/V 失效，测试无效 | NOT TESTED |
| E-11 | 多行 / 回车 | 模拟器无可用多行编辑器 | NOT TESTED |
| E-12 | 第三方日记 App | 模拟器未安装 | NOT TESTED |

详细命令、依据链与风险分析见 [PHASE0-HDC-SPIKE.md](PHASE0-HDC-SPIKE.md)。

## 6. 最终决策记录

- **推荐路线：** B — HDC + `uitest uiInput text` 文本提交（模拟器可行，真机待定）
- **已排除路线：** 标准 scrcpy / UHID（目标系统无 adb）；`uinput` 键盘模拟（仅 ASCII，无法输入中文）
- **系统原生键鼠共享：** 未验证；非华为电脑预期不受支持
- **是否需要开发 Windows 助手：** 取决于真机结论；若 B 通过，Windows 端只做"连接 + 编辑框 + 发送"外壳
- **是否需要 HarmonyOS 接收端：** B 路线**不需要**；仅当 B 在真机失效且输入法扩展可行时才考虑
- **真机已验证能力：** 无
- **模拟器已验证能力：** 中文/ASCII 文本注入、清空、命令延迟；方向键与多行未通过
- **阻塞与未解决问题：** ① 手机未连接，无任何真机数据；② 零售机上 `uitest` 是否可用未知（官方文档存在"仅 aa test 测试 HAP 可调用"的限制说明）；③ 中文注入是否走剪贴板未知；④ 多行/回车/光标语义未知
- **结论状态：** **PENDING REAL DEVICE** — 不可宣布 Phase 0 已通过
